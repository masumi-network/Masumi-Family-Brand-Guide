# Cuso 2D mascot

The approved 2D Cuso character for CMO.XYZ. Every file comes as an SVG and a transparent PNG, 3000 px on its longest side.

## Folders

- `poses/<pose>/svg/` and `poses/<pose>/png/`: walking, pointing, friendly, thinking, researching, idea, done
- `expressions/<expression>/svg/` and `expressions/<expression>/png/`: default, cool, nervous, angry, sad, in-love

## Variations

| File ending | What it is | Available for |
|---|---|---|
| `-default` | Black lines and white fill, no outline, no ground shadow | Poses and expressions |
| `-white-outline` | Adds the white sticker edge | Poses and expressions |
| `-ground-shadow` | Adds the black shadow under the feet | Poses |
| `-ground-shadow-white-outline` | Ground shadow and white sticker edge | Poses |

Example: `poses/walking/png/cuso-walking-white-outline.png`

## Rules

- Use approved poses and expressions only.
- Cuso never wears gloves.
- Never stretch or recolor Cuso.
