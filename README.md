# Masumi Family Brand Guide

Brand and UI/UX source of truth for Masumi, Sokosumi (Marketing OS) and CMO.XYZ.

- `Masumi Family design.md`: the guide. Open it next to the image folders so the images show.
- `logos/`: wordmarks and symbol, one folder per brand, plus partner logos.
- `Agentic Family Brand Slides/`: all brand slides as images: Agentic family, logo clearspace, spacing, partnerships and typography.
- `Cuso 3D Mascot/`: Cuso avatars, render and 3D model for CMO.XYZ.
- `sources/`: editable HTML sources for the slides.
